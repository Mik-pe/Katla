# Reusable material authoring evidence

A contextual participant used a disposable Linux/Vulkan editor built from
`f1e82612`, with shader sources fixed. The parent started the editor and supplied
a transport helper, without editing its scene. The [report](observations.md),
[transcript](transcript.jsonl), [exact comparisons](comparisons.json), nine native
PNGs, [definition](helmet.katmat) and [scene](authored-material-assets.katla)
preserve the session. Resource references use the original project assets.

The 42 calls verify capture/reuse, independent copies and file revisions,
validation/recovery, full-material history and fresh-ID scene reconstruction.
The final frame is byte-identical after reload. This is one contextual episode,
not a general LLM preference survey; numeric GPU fixtures remain the rendering
correctness gate. Physical Metal validation is unavailable on this Linux host.
