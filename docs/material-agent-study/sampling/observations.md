## Friction and requested improvements

- The `role` + partial `patch` shape is effective. Before/current receipts, image-binding preservation and decimal-string IDs make edits reviewable. Sampling and image assignment are clearly distinguished. The current discovery also exposes alpha-mode/emission edits unavailable in the prior interface study; I did not test those paths in this sampling episode.
- Asset search gives usable paths but no texture/UV metadata. I chose the helmet and inspected after spawning. A lightweight asset material summary or preview would help find a textured/UV-capable candidate without trial spawning.
- Per-role transforms are intentionally independent. The unchanged cyan markings during the albedo experiment visibly show why this matters: an atlas-dependent prop becomes incoherent when only albedo moves. A multi-role patch or explicit linked-role operation would help keep albedo/normal/metallic/occlusion aligned as one undoable edit when that is the user's intent. This study deliberately edited roles independently.
- UV availability and sampler errors are clear, actionable and structured. A stable error code, offending decimal ID, role and field would avoid parsing prose containing `Entity(29:0)`.
- Anisotropy reports the requested integer and says it will be clamped to the device maximum, but exposes no effective integer/device limit in this inspection. Report requested and effective values separately. I verified accepted values and persistence, not GPU anisotropy level or quality.
- Normal provenance reports `kind: reconstructed_from_current_uv` while `generated_uv` still contains the original identity transform. I interpreted the latter as the stored original basis generation context, but this distinction is not explicit. Rename/split original generation UV and current shading basis details so authors need not infer their relationship.
- Inspection is comprehensive but lengthy: all capabilities, five provenance records and five role states repeat. An optional role selector/compact inspection could shorten iterative calls; retain a full mode for provenance audits.
- Undo/redo supplies native frames but no operation/changed-role receipt. Return affected IDs/role and before/current sampling with history results to make recovery explicit.
- Useful unexposed actions would include resetting a role to imported sampling, texture thumbnails or UV debug overlay, and linked map transforms. The current tool correctly reports texture assignment unavailable; these are requested capabilities, not features demonstrated here.

The screenshots establish visible sampling consequences in this single native editor episode. They do not establish every sampler mode, device limit, exact tangent math, mip policy, or another backend's behavior.
